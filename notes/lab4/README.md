## 本轮实现前确定的用例

- T4-1：三个纯计算进程与逐 tick 观察者；观测 1/2/4 片长，统一预热后比较 CPU 增量，验证同级轮转。
- T4-2：低级计算后台与每轮 pause(1) 的交互子进程；验证 level 0、短片长、有界唤醒延迟、后台推进。
- T4-3：schedstat 指针/PID 边界、setickets 边界、pause、kill 睡眠进程、wait 错误指针与槽位耗尽后恢复。
- T4-4：两个不调用 pause 的计算子进程分别输出 A/B，要求输出交错、各 16 字节并完整回收。

规格先于内核重构写入工作树。实现后补充了公平性统一采样窗口和精确 PID 快照；结果为三计算进程 64:64:64、交互最大间隔 4 tick、可创建子进程 62 个、全部回收后可再次 fork。

- 每进程 p->lock、每 CPU context/proc/noff/intena；sched 四条断言及跨 swtch 锁交接。

- 三级逻辑队列，每级独立轮转游标；仅用户态时钟统计与抢占。
