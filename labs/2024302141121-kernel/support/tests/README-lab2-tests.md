# lab2 官方用户态测试集（课程组提供 · 评分参考）

构建方式：与 sh/hi/spin 一致采用内嵌方式 —— 在 Makefile 的 `UPROGS` 后追加
`badecall bufstorm`（或参考《能力目标与接口约定》的合并方式）。

| 测试程序 | 测试覆盖范围 | 判定合格标准 | 运行与驱动方式 |
|---|---|---|---|
| `badecall` | 未知或非法系统调用返回 -1、不崩溃 | 终端输出 `TEST-1 PASS`；sh 正常存活 | 直接在终端执行 |
| `bufstorm` | 输入缓冲区边界与溢出语义 | 连续读取 4 行并完整回显，输出 `BUFSTORM lines=4`；配合 `inject_uart.py --script` 模拟输入超长行（长度超过个人 `LAB2_BUF_SIZE`）验证字符统计正常、内核不崩溃 | 终端执行并配合 inject_uart.py 模拟超长连续输入 |

验收标准：两项测试均通过即视为本项功能演示合格；`bufstorm` 针对超长行丢弃字符的现象属于缓冲区已满时的预期设计行为（已在设计笔记中明确说明），不记为失败，但测试完成后内核必须保持正常稳定运行。
