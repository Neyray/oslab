> 整理自 `06-学生环境安装指引.docx`。原始文档见 [`materials/06-学生环境安装指引.docx`](../materials/06-学生环境安装指引.docx)。

- **什么时候做**：第 1 次课当堂安装，装完立刻自检。
- **装什么**：RISC-V 交叉编译器、QEMU 模拟器、git、python3、perl。
- **自检工具**：`preflight.py`（副本在 [`materials/preflight.py`](../materials/preflight.py)）。

> ✅ **本机状态**：Windows 11 + WSL2 (Ubuntu-22.04)，工具链已装齐，见本仓库 [README](../README.md#环境状态) 的环境状态表。

## 一、macOS

```bash
# 1) 安装 Homebrew（已装可跳过）
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 2) 安装工具链与 QEMU
brew install riscv64-elf-gcc riscv64-elf-binutils qemu

# 3) 统一命令名（课程脚本按 riscv64-unknown-elf-* 寻找）
for t in gcc ld objdump gdb addr2line readelf; do
  [ -e "$(brew --prefix)/bin/riscv64-elf-$t" ] && \
  ln -sf "$(brew --prefix)/bin/riscv64-elf-$t" "$(brew --prefix)/bin/riscv64-unknown-elf-$t"
done
```

国内网络慢时，可先给 brew 换清华 / 中科大镜像（搜"Homebrew 国内镜像"）。

## 二、Windows：用 WSL2

> 不是 PowerShell，也不是 Cygwin。

1. **管理员 PowerShell** 执行 `wsl --install`（默认装 Ubuntu），重启后设置用户名密码。
2. 进入 Ubuntu 终端（开始菜单搜 Ubuntu），执行：

```bash
sudo apt update
sudo apt install gcc-riscv64-unknown-elf binutils-riscv64-unknown-elf \
     qemu-system-misc git perl python3
```

3. **建议**：把实验代码放在 WSL 文件系统内（如 `~/oslab/`），**不要放在 `/mnt/c/`**——跨文件系统 I/O 会慢 10 倍以上。

> 本仓库即位于 WSL 文件系统内：`~/projects/oslab`。

## 四、自检（装完立刻做）

把课程平台的 `preflight.py` 放到任意目录，执行：

```bash
python3 preflight.py
```

**期望输出要点**：

- `riscv64-unknown-elf-gcc` / `-ld` / `-objdump` / `qemu-system-riscv64` / `python3` 全部 `[ ok ]`
- `[warn] riscv gdb 不可用` —— **正常**，本课程不用 gdb，有完整的替代调试方案
- 最后一行 `结论:环境自检通过` —— 自检完成

> 📸 把**完整输出**截图留好，第 1 次课教师会查。

若最后一行提示缺少必要组件，按提示回到对应步骤补装。

### preflight 还会做什么

除了查工具，它会组装两个最小内核（带 / 不带 PMP 配置）在 QEMU 里 `mret` 进 S 态，通过 QEMU monitor 读 `priv`，实测本机 QEMU 版本**是否要求 PMP 授权才能在 S 态取指**——这直接对应 lab1 黑屏最常见的原因（`cause=1` 取指访问错）。

## 五、排障三步（自检不过时）

1. **核对命令名**：`which riscv64-unknown-elf-gcc` 应有输出。macOS 用户重点检查第一节第 3 步的软链接是否配好。
2. **重开终端再试**：装完不重开终端，`PATH` 不会刷新。
3. **求助**：把 preflight 的**完整输出**发给教师（不要只截图最后一行）。

## 六、常见问题

| 问题 | 处理 |
| --- | --- |
| 磁盘空间 | 全部工具 + 一个实验树 < 2 GB |
| brew 报错 / 下载慢 | 换国内镜像源后重试 |
| `wsl --install` 失败 | 在 BIOS 打开虚拟化（VT-x / AMD-V）；或在"启用或关闭 Windows 功能"里勾选"适用于 Linux 的 Windows 子系统"与"虚拟机平台" |
| Apple Silicon（M 系列） | 完全支持，QEMU 与工具链均有原生 arm64 版本，性能很好 |

## 七、装完之后

环境只是起点。调试内核请阅读《[学生无 gdb 调试手册](07-无gdb调试手册.md)》，掌握三项核心手段：

- 异常日志分析 `-d int`
- 指令执行追踪 `-d in_asm`
- QEMU Monitor 监控

结合内核自身的观测输出，开展全学期的实验排查与调试。
